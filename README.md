# Predicción de Compra y Venta de Bitcoin (BTC)
### Desarrollo de Aplicaciones para el Análisis de Datos — ESCOM IPN

## 📌 Descripción
Sistema de predicción de señales de compra y venta de Bitcoin
mediante machine learning, aplicando la metodología CRISP-DM
e integrando web scraping como fuente de datos complementaria.

## 🔧 Tecnologías
- Python 3.11+
- requests + BeautifulSoup4 (Web Scraping)
- yfinance (Datos históricos BTC)
- pandas, NumPy (Procesamiento)
- scikit-learn, XGBoost (Modelos ML)
- matplotlib, seaborn (Visualización)

## 🗂️ Metodología
Este proyecto sigue la metodología CRISP-DM:
1. Entendimiento del Negocio
2. Entendimiento de los Datos ← Web Scraping
3. Preparación de los Datos
4. Modelamiento
5. Evaluación
6. Publicación
